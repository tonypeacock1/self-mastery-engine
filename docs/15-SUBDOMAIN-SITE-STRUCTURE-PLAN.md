# 15 — Research-Driven Subdomain & Site Structure Plan
**Date:** 2026-08-22
**Basis:** 213 SERP lookups (93 head + 120 long-tail), volumes, sentiment, Slovak conversion analysis

## Principle
- Rank on **problem language** (HIGH SERP gaps), convert on book + Instant EFT.
- One Cloudflare Pages property can host pillar + geo spokes OR separate properties per major SILO.
- GitHub orgs/repos for rankable github.io properties follow keyword-org naming only where we intentionally rank the GitHub URL.

2. Able-person recognition (still showing up, wants capacity)

4. FAQ schema from long-tail questions
5. Soft CTA → book Instant EFT (decide-for-yourself tone from Slovak proof)
6. Internal links to sibling cluster pages

## What NOT to build first

- Clinical diagnosis URLs
